# Руководство пользователя

Этот документ объясняет, как конечный пользователь (клиницист, исследователь,
студент) взаимодействует с **Medical Imaging Dataset Aggregator**.

> Объём проверенного MVP (снапшот интеграционного теста): **Каталог**, **Страница датасета**, **Поиск**.
> Аутентификация, персональные коллекции и «Мои датасеты» — **запланированы** на следующую итерацию.

---

## 1. Доступ к приложению

1. Откройте приложение в браузере.
   Пример: `http://<server-host>/`
2. Если в вашем развёртывании включена аутентификация, нажмите **“Log in”**.
3. Если аутентификация ещё не включена, продолжайте как гость (публичный каталог/поиск).

<screenshot: auth-page>

Точные подписи и названия полей зависят от финальной реализации фронтенда.
Замените плейсхолдеры реальными скриншотами, когда UI будет стабилен.

---

## 2. Главный экран (поиск)

Обычно вы попадаете на страницу **Search**, где есть:

- поле **текстового поиска**;
- **фильтры**, например по:
  - модальности;
  - анатомической области;
  - типу ML-задачи;
  - тегам;
- таблица с **результатами поиска**.

В навигации обычно есть:

- **Search**;
- **My datasets** (планируется);
- (для админов) **Admin**.

<screenshot: main-search-page>

---

## 3. Поиск датасетов

### 3.1 Базовый поиск

1. Введите запрос в поисковую строку.
   Примеры:
   - `pneumonia chest xray`
   - `пневмония грудная клетка КТ`
2. Опционально примените фильтры:
   - Modality = X‑ray;
   - Area = Chest;
   - Task type = Classification.
3. Нажмите **Search**.

Таблица покажет датасеты, подходящие под запрос:

- название и источник;
- модальности/задачи/теги (если заполнены);
- приблизительный размер (если доступен).

<screenshot: search-results>

### 3.2 Просмотр деталей датасета

Кликните на строку датасета или кнопку **“Details”**, чтобы увидеть:

- описание;
- ссылку на оригинальный ресурс;
- метаданные (анатомическая область, лицензия, размер, теги и т.п.).

---

## 4. Сбор пользовательской коллекции (планируется)

В целевом продукте пользователь сможет:

- выбрать один или несколько датасетов в результатах поиска;
- настроить параметры (например, лимиты по количеству изображений);
- запустить сборку и затем скачать архив.

В протестированном MVP снапшоте этот поток может быть недоступен.

---

## 5. «Мои датасеты» / история (планируется)

В будущем раздел **My datasets** будет показывать ранее собранные коллекции:

- ID/название;
- исходный запрос;
- дата создания;
- статус (Pending / Ready / Expired);
- действия (Download / Regenerate).

<screenshot: my-datasets-page>

---

## 6. Выход из системы

Нажмите на иконку профиля или пункт меню с вашим именем и выберите **“Log out”**.

---

## 7. Частые проблемы и подсказки

- **«Ничего не найдено»**
  - Ослабьте фильтры или упростите запрос.
  - Проверьте, что в каталоге действительно есть датасеты для выбранной модальности/задачи.
- **Поиск «долго думает»**
  - Если включён поиск по внешним источникам, задержки возможны из-за сети и лимитов API.
  - Для воспроизводимых демо используйте локальный каталог.
