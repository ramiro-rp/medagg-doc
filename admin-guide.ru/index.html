Руководство администратора

Это руководство предназначено для пользователей с ролью Admin в Medical Imaging Dataset Aggregator.

Примечание (снапшот тестов): в протестированном MVP администрирование выполнялось через Django Admin (обычно доступен по пути /admin/). Отдельная админ-страница во фронтенде планируется на более позднюю итерацию.

1. Обязанности администратора

  • поддерживать каталог датасетов и справочники в актуальном состоянии;
  • помогать диагностировать проблемы с интеграцией/поиском;
  • контролировать использование ресурсов (БД/диск), если включены сборки коллекций.

2. Доступ к панели администратора

  1. Войдите в систему под учётной записью с правами администратора.
  2. Откройте Django Admin по адресу:
  3. http://<server-host>:8000/admin/ (по умолчанию)

Если раздел администрирования недоступен, у вашей учётной записи нет необходимых прав.

3. Управление датасетами

3.1 Создание записи датасета

  1. Перейдите в Datasets → Datasets.
  2. Нажмите Add.
  3. Заполните минимум:
  4. title;
  5. external source URL;
  6. short description;
  7. anatomical area (если применимо);
  8. license (в тестируемом контракте фронтенд ожидает это поле);
  9. tags / modalities / ML tasks (если применимо).
  10. Сохраните изменения.

3.2 Редактирование

  1. В списке датасетов выберите нужный.
  2. Измените поля и сохраните.

4. Управление справочниками

Администратор может поддерживать согласованность справочников:

  • Anatomical areas;
  • Modalities;
  • ML task types;
  • Tags.

Консистентные справочники важны для фильтров и поиска.

5. Запросы и коллекции (планируется)

В целевой версии продукта админ-панель может показывать:

  • запросы пользователей;
  • статус сборки коллекций;
  • ошибки и логи.

В протестированном MVP снапшоте этот раздел может отсутствовать.

6. Безопасность

  • не передавайте админ-пароли третьим лицам;
  • ограничьте доступ к админке из недоверенных сетей;
  • храните секреты (DB пароли, API токены) в переменных окружения;
  • при подозрении на компрометацию — обновите секреты и уведомите команду.
